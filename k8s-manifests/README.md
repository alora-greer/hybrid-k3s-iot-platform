# k8s-manifests

Plain Kubernetes YAML applied after `terraform/k8s-addons` has installed the
CRDs (Prometheus Operator, SealedSecrets, K8sGPT).

| Directory | Contents |
|---|---|
| `monitoring/` | Home Assistant `ScrapeConfig`, `PrometheusRule`s, Grafana `Ingress` |
| `cloudflared/` | Cloudflare Tunnel `Deployment` + metrics `ServiceMonitor` |
| `k8sgpt/` | `K8sGPT` resource pointing at local Ollama |

Environment-specific values are written as `${VAR}` and substituted from
`.env` by `make render` (only an explicit allow-list of variables is replaced).
Secrets are committed only as `*.sealedsecret.yaml`, generated by
`make seal-*`.

```bash
make render   # -> .rendered/ (gitignored)
make diff
make apply
```
